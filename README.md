# Время видимости МКС с Земли

Лабораторные работы по дисциплине «Разработка интернет-приложений».
Вариант 18: определение времени видимости МКС с Земли.

`Услуга` предметной области — **точка наблюдения**: место на Земле с координатами наблюдателя,
из которого отслеживают пролёты Международной космической станции.

## Стек

- Go 1.25, веб-фреймворк `gin-gonic`
- PostgreSQL 16, доступ к данным через ORM `gorm`
- Minio в Docker — хранилище изображений и видео
- стандартный шаблонизатор `html/template` — страницы из второй лабораторной
- без JavaScript, CSS вынесен в отдельный файл

## Методы веб-сервиса

Адрес каждого метода начинается с `/api`. Системные поля — идентификатор, статус,
создатель, признак модератора, даты создания и формирования — с клиента на изменение
не принимаются: их подставляет бизнес-логика.

Создатель услуги во всех методах взят из функции-singleton
`auth.CurrentUserSingleton()` и зафиксирован константой до появления авторизации
в четвёртой лабораторной.

В теле ответа сообщений об ошибках нет: код состояния передаётся отдельным
параметром HTTP-ответа. Статус услуги в JSON не выводится вообще.

### Домен услуги — точка наблюдения

| Метод и URL | Тело запроса | Коды ответа | Что делает |
|---|---|---|---|
| `GET /api/observation_points?min_latitude=` | — | 200, 400 | Список опубликованных услуг. Фильтрация по широте выполняется базой. Для каждой записи возвращается признак `is_mine` 0/1 |
| `GET /api/observation_points/feed` | — | 200, 404 | Лента: первая опубликованная услуга, одна запись |
| `GET /api/observation_points/:id` | — | 200, 400, 404 | Опубликованная услуга по идентификатору |
| `GET /api/observation_points/:id?next=true` | — | 200, 400, 404 | Следующая опубликованная услуга после указанной, по кругу, минуя удалённые |
| `GET /api/observation_points/draft` | — | 200, 404 | Черновик текущего пользователя. Идентификатор не указывается: черновик не более одного |
| `POST /api/observation_points` | `multipart/form-data`: `name`, `description`, `image`, `video` | 201, 400, 409 | Создание черновика вместе с файлами. Файлы уходят в Minio, в базу пишутся имена, сгенерированные на латинице. 409 — черновик уже есть |
| `PUT /api/observation_points/:id/publish` | `{"latitude": …, "longitude": …}` | 200, 400, 404 | Публикация: статус меняет бизнес-логика, с клиента он не приходит |
| `DELETE /api/observation_points/:id` | — | 204, 400, 404 | Логическое удаление. Только своя услуга, строка остаётся в таблице |
| `POST /api/observation_points/:id/like` | `{"value": 0 или 1}` | 200, 400, 404 | Отметка «нравится» от текущего пользователя: 1 ставит, 0 снимает |

Вернуть услугу в черновик нельзя: метода для такого перехода нет. У создателя
два разных метода — создание черновика и публикация.

### Домен пользователя

| Метод и URL | Тело запроса | Коды ответа | Что делает |
|---|---|---|---|
| `POST /api/users` | `{"login": …, "password": …}` | 201, 400, 409 | Регистрация. Идентификатор и признак модератора с клиента не принимаются, 409 — логин занят |
| `POST /api/users/login` | — | 200, 500 | Аутентификация. Заглушка до четвёртой лабораторной: возвращает пользователя из функции-singleton |
| `POST /api/users/logout` | — | 204 | Деавторизация. Заглушка до четвёртой лабораторной: сессии пока нет |

### Поля ответа с услугой

Набор полей одинаков во всех методах, потому что ответ собирает один сериализатор
`dto.ObservationPoint`.

| Поле | Тип | Смысл |
|---|---|---|
| `id` | число | Идентификатор услуги |
| `name` | строка | Название точки наблюдения |
| `description` | строка | Описание |
| `image_url` | строка | Адрес изображения в Minio |
| `video_url` | строка | Адрес видео в Minio |
| `latitude` | число или `null` | Широта, от −90 до 90 |
| `longitude` | число или `null` | Долгота, от −180 до 180 |
| `likes` | число | Количество отметок «нравится», вычисляется запросом |
| `liked` | 0 или 1 | Отметка текущего пользователя |
| `is_mine` | 0 или 1 | Создатель услуги совпадает с текущим пользователем |
| `date_created` | дата | Дата создания черновика |
| `date_formed` | дата или `null` | Дата публикации |

Полей `status` и `creator_id` в сериализаторе нет, поэтому статус услуги
и идентификатор создателя клиенту не передаются ни при каких условиях.

## Таблицы базы данных

### `observation_points` — услуга предметной области

| Поле | Тип | Ограничения | Смысл |
|---|---|---|---|
| `id` | `serial` | первичный ключ | Идентификатор |
| `name` | `varchar(100)` | `not null` | Название точки наблюдения |
| `description` | `varchar(500)` | | Описание |
| `status` | `varchar(20)` | `not null` | `черновик`, `опубликован` или `удален` |
| `image_url` | `varchar(200)` | | Адрес изображения в Minio |
| `video_url` | `varchar(200)` | | Адрес видео в Minio |
| `latitude` | `double precision` | | Широта, заполняется при публикации |
| `longitude` | `double precision` | | Долгота, заполняется при публикации |
| `date_created` | `timestamptz` | `not null` | Дата создания черновика |
| `date_formed` | `timestamptz` | | Дата публикации |
| `creator_id` | `integer` | `not null`, внешний ключ на `users` | Создатель услуги |

Частичный уникальный индекс `idx_one_draft_per_creator` по полю `creator_id`
с условием `where status = 'черновик'`: у пользователя не может быть двух
черновиков одновременно, а число опубликованных и удалённых услуг не ограничено.

### `users` — пользователь

| Поле | Тип | Ограничения | Смысл |
|---|---|---|---|
| `id` | `serial` | первичный ключ | Идентификатор |
| `login` | `varchar(25)` | `not null`, уникальное | Логин |
| `password` | `varchar(100)` | `not null` | Пароль. Хеширование появится в четвёртой лабораторной вместе с авторизацией |
| `is_moderator` | `boolean` | по умолчанию `false` | Признак модератора |

Пароль в ответах веб-сервиса не возвращается: сериализатор `dto.User`
отдаёт только идентификатор, логин и признак модератора.

### `observation_point_likes` — отметки «нравится», связь многие-ко-многим

| Поле | Тип | Ограничения | Смысл |
|---|---|---|---|
| `id` | `serial` | первичный ключ | Идентификатор |
| `user_id` | `integer` | `not null`, внешний ключ на `users` | Кто отметил |
| `observation_point_id` | `integer` | `not null`, внешний ключ на `observation_points` | Что отмечено |

Составной уникальный индекс `idx_user_observation_point` по паре
`user_id` и `observation_point_id`: один пользователь не может отметить
одну услугу дважды. Количество отметок в таблице услуг не хранится,
оно считается запросом с `LEFT JOIN` и `COUNT`.

## Страницы и маршруты

Страницы остались со второй лабораторной работы. Веб-сервис третьей
лабораторной работает отдельно от них и показывается в Postman.

| Метод и URL | Страница | Что делает |
|---|---|---|
| `GET /feed` | Лента | первая опубликованная точка; так на неё ведёт панель вкладок |
| `GET /feed/:id` | Лента | точка по идентификатору |
| `GET /feed/:id?next=true` | Лента | следующая точка после указанной, по кругу |
| `GET /add` | Добавление | единственная точка в статусе «черновик» |
| `GET /observation_points?min_latitude=` | Плитка | список точек с фильтрацией по широте |

Точки в статусе «удален» не отображаются и не отдаются по прямому запросу.

Поля предметной области — **широта и долгота**. Полушарие вычисляется по знаку координаты,
поэтому Голдстоун и обсерватории Чили подписаны как западная долгота, а не восточная.

Фильтр — ползунок с кнопкой, диапазон от −90° до 90°. Значение передаётся GET-параметром
`min_latitude` и возвращается в шаблон, поэтому сохраняется между запросами. Нечисловое значение
и выход за диапазон дают сообщение над списком, некорректный идентификатор — код 400,
несуществующая точка — 404.

## Запуск

```bash
docker compose up -d          # PostgreSQL, Minio и Adminer
go mod tidy
go run ./cmd/migrate          # таблицы и индексы
go run ./cmd/seed             # данные для показа
go run ./cmd/iss-visibility   # сервер
```

| Что | Адрес |
|---|---|
| Веб-сервис | http://localhost:3001/api |
| Страницы со второй лабораторной | http://localhost:3001/feed |
| Консоль Minio | http://localhost:9201 (`minioadmin` / `minioadmin`) |
| Хранилище Minio | http://localhost:9200/iss-visibility |
| Adminer | http://localhost:8082 (сервер `postgres`, база `iss_visibility`) |
| PostgreSQL | `localhost:5433` |

Порты смещены относительно стандартных, потому что `9000`, `5432` и `8080`
на машине разработки заняты другими проектами. Адрес хранилища
переопределяется переменной окружения `MINIO_PUBLIC_URL`.

## Структура

```
cmd/iss-visibility/      точка входа: собирает конфиг, репозиторий, обработчик и приложение
cmd/migrate/             миграции: создание таблиц и индекса черновика
cmd/seed/                заполнение базы данными для показа
config/config.toml       адрес сервиса и адрес хранилища
internal/pkg/            Application: регистрация маршрутов, статики и запуск сервера
internal/app/config/     чтение config.toml через Viper
internal/app/dsn/        строка подключения к базе из переменных окружения
internal/app/auth/       функция-singleton с текущим пользователем
internal/app/ds/         модели: описание таблиц базы, без json-тегов
internal/app/repository/ доступ к данным через gORM и загрузка файлов в Minio
internal/app/dto/        сериализаторы: описание ответа веб-сервиса
internal/app/handler/    обработчики запросов
templates/               шаблоны трёх страниц и панели вкладок
resources/styles/        CSS
resources/icons/         иконки Material Symbols (Apache 2.0)
resources/fonts/         шрифт Commissioner (SIL Open Font License)
resources/img/           изображение по умолчанию
resources/video/         видео по умолчанию
assets/                  исходники изображений и видео для загрузки в Minio
```

## Дизайн

Стилистика скопирована с сервиса слежения за МКС **ISS Tracker** (https://isstracker.pl).
Палитра снята из его таблиц стилей через DevTools:

| Элемент | Цвет | Правило у донора |
|---|---|---|
| Фон страницы | `#F5F5F9` | `--light` |
| Текст | `#556899` | `body` |
| Заголовки, кнопки, числа | `#022170` | `h1…h6` |
| Рамка карточки | `#EFEEF1` | `.card` |
| Рамка поля ввода | `#DCDCE5` | `.form-control` |
| Приглушённые подписи | `#BBB9CC` | `.text-muted` |
| Отметки «нравится» | `#DC3546` | `--red` |
| Тень карточки | `rgba(35, 38, 62, .08)` | `.shadow-sm` |

Донор набран шрифтом Barlow, кириллицы в нём нет. Поэтому весь сайт набран **Commissioner** —
гротеском того же класса с полным кириллическим набором. Шрифт лежит в проекте двумя файлами,
латиница и кириллица разделены по `unicode-range`, внешние подключения не используются.

Макет вертикальный, 390 × 844, без адаптивности. Панель вкладок вынесена вниз и оформлена
плавающей скруглённой полосой.
